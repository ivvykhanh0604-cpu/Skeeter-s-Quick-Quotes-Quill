# Quick-Quotes Quill 🪶
What if your ordinary stories were rewritten by a ridiculously dramatic, gossipy journalist?

Inspired by Rita Skeeter's Quick-Quotes Quill from Harry Potter, this interactive tool transforms overheard news into 5 distinct narrative styles, from sensationalist gossip to tragic poetry. Users can choose a writing personality, adjust the dramatic intensity, and generate a rewritten version using Google's Gemini API.

Built with: Python, Streamlit, Google Gemini API.
